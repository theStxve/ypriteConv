# Changelog

## 1.1.0

- Thumbnails for photos, videos and PDFs in the file list
- Size before and after for every converted file, plus the total saved
- Video options: rotate or mirror, change the resolution, trim, remove audio, and fit into a file size (for example 25 MB for Discord). Use them on one video or all of them
- Videos can be re-encoded in the same format (to rotate, trim or shrink an MP4)
- Combine images and PDFs into one PDF (sort by dragging, original size or A4), and split a PDF into single pages
- Several files convert at the same time, so large batches finish much faster
- Paste with Ctrl+V: files copied in Explorer, or an image such as a screenshot
- Progress shown on the taskbar button
- The app remembers your last target format for each file type
- German interface (follows the Windows language, or choose it in Settings)
- Welcome screen on first start with output folder, theme, right-click menu and update settings
- "What's new" after every update, and the full changelog under Settings > About
- Right-click menu entry can now be switched on or off in Settings

## 1.0.1

- Fixed: file status in the list stayed on "Queued" during conversion (files were converted, but progress, "Done" and errors were not shown)

## 1.0.0

First public release.

- New interface: clean light and dark themes that follow Windows, a large drop area and a clear file list
- Real file type detection: files with wrong or made-up extensions are recognised by their content and can be restored or converted
- HEIC/HEIF support (iPhone photos), with EXIF data and rotation kept
- PDF → images renders every page in high resolution; PDF → Word and PDF → text
- Video → MP3/WAV/M4A and video → GIF
- Workflows (multi-step presets) such as Podcast Publisher and YouTube Ready
- Saves next to the original or to a fixed folder, and never overwrites existing files
- Cancel at any time, live progress, and a clear error message for every file
- Right-click "Convert with ypriteConvert" in Explorer
- Automatic updates via GitHub Releases
- FFmpeg included, no setup needed
